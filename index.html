Debug texture types

Checker Board

Alternating black/white or color squares. Reveals UV tiling scale issues, seams, and incorrect UV unwrapping at a glance.

UV Grid

Grid with numbered cells and directional indicators. Verifies UV layout, detects distortion, flipping, and UV island alignment.

Color Ramp

Horizontal or vertical gradient. Verifies texture coordinate interpolation direction and checks for UV flipping.

Normal Map Test

Pattern that tests tangent space normal map response. Reveals incorrect normal map settings (DirectX vs OpenGL), inverted channels.

Mip Level Indicator

Different colors per mip level. Shows which mip level is being used at different viewing distances — diagnoses mip chain issues.

Solid Color

Single flat color. Use for material slot isolation, render target debugging, or as a base for custom debug materials.

How to use debug textures

Diagnosing UV issues with a checker board texture
Apply a checker board debug texture to your mesh. Uniform, square checks indicate correct UV mapping. Irregular checks (stretched, compressed, or skewed) indicate UV distortion at that region. Visible hard seams indicate UV island boundaries that need better placement. Broken or mirrored patterns indicate overlapping UVs or incorrect UV unwrap direction. The tile count on the debug texture should match your intended texture scale — if squares look too small, your UVs are too large relative to your intended texel density.

Using UV Grid textures in Unity and Unreal Engine
Unity: Download the PNG, drag into Assets, create a Material, set Albedo texture, apply to mesh. Unreal Engine: Import PNG to Content Browser, create Material with Texture Sample node connected to Base Color, apply to mesh. In both engines, the UV Grid will immediately show numbered cells that let you identify specific UV islands and their orientation. A cell reading upside-down indicates a flipped UV island.

Normal map direction testing
Apply the normal map test texture and view in a 3D engine with a directional light. If the normal map is responding incorrectly (flat-looking, reversed shadows), check: DirectX vs OpenGL normal map format (Unity HDRP uses DirectX, Blender exports OpenGL by default), Y channel inversion, and tangent space settings. The test pattern contains both concave and convex elements so you can immediately see if lighting responds correctly.

FAQ — Debug textures
A debug texture is a test image applied to 3D meshes to diagnose UV mapping, tiling, and texture coordinate issues. A checker board reveals UV scale and seams. A UV grid shows UV island orientation and distortion. A color ramp verifies UV interpolation direction. Debug textures are used in Unity, Unreal Engine, Blender, Maya, Cinema 4D, and any 3D workflow where UV quality needs to be verified.
Generate and download the PNG from this tool. In Unity: (1) Drag the PNG into your Assets folder. (2) Create a new Material (Assets → Create → Material). (3) In the Material Inspector, set the Albedo texture to the debug texture PNG. (4) Apply the material to your mesh by dragging it onto the object. The checker or UV grid will immediately reveal UV issues. For Unreal: import the PNG, create a Material, add a Texture Sample node, connect to Base Color, assign texture, apply to mesh.
Use power-of-two sizes for GPU compatibility: 256×256, 512×512, 1024×1024, or 2048×2048. 512×512 is sufficient for most UV debugging — it provides enough detail to see distortion without being too large to load quickly. For high-detail UV inspection on large meshes, 1024×1024 or 2048×2048 gives more granularity. All sizes generated by this tool are power-of-two and compatible with all major 3D engines and GPU texture samplers.
Stretched checker squares indicate UV distortion — the UV map does not correctly represent the 3D surface. Causes: (1) Non-uniform scaling applied to the mesh before UV unwrapping. Fix: Apply the transform (Ctrl+A in Blender) before unwrapping. (2) Incorrect projection method during unwrap. Use Smart UV Project or Manual seams for complex objects. (3) UV islands that were scaled non-uniformly. Select all UV islands in the UV editor and use uniform scale. (4) High-curvature areas that need additional seams to flatten correctly.
